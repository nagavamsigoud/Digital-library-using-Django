# Security policy

This repository is an educational/demo application. Do not use it to process real payments or sensitive financial data.

## Reporting a vulnerability

Please do not publish exploitable details in a public issue. Contact the repository maintainer privately through the contact method listed on the maintainer's GitHub profile. Include affected paths, impact, and reproduction steps where safe.

## Supported versions

Only the latest code on the default branch is intended to receive fixes. No formal support or response-time SLA is offered.
